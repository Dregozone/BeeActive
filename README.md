# BeeActive

![status: archived](https://img.shields.io/badge/status-archived-lightgrey)

> **⚠️ Archived Repository**  
> This project is no longer actively maintained.  
> It remains available for reference and historical purposes.

## Overview
This project provided an application for managing personal fitness, nutrition and weight goals. There are unlockable achievements and many configurable settings to make the app work for your needs. The intended use case included tying to lose weight with bite-sized, realistic daily goals and allowing users to track their daily macros against calculated values based on their specific scenarios.

## Reason for Archive
BeeActive has been rebranded, and all development has continued under the new name **Atlas Fit**. The successor project enables users to manage their fitness and nutrition goals with unlockable achievements and manage their weight with surplus and deficit goals in place.
